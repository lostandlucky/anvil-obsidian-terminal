# Reference

Hand-written reference docs for the plugin's public surface: commands, settings, and the core classes that make up the terminal view. One file per logical unit. Third-person, factual, no procedural steps — if you want to *do* something, see `../how-to/`.

- [architecture.md](architecture.md) — the three-pieces system map and how they connect.
- [terminal-container-view.md](terminal-container-view.md) — the `ItemView` subclass that hosts the terminal tabs.
- [pty-backend.md](pty-backend.md) — the TypeScript driver for the `pty-server` binary.

See `../DOCUMENTATION_STANDARDS.md` for what belongs here and the voice to use.
