# How-Tos

Task-oriented guides. Titles are problems ("How to run the e2e suite"), not features. Second-person, imperative, minimal backstory. If a step needs justification, link to an ADR rather than explaining inline.

Seed topics (to be written by `/document`):

- `dev-setup.md` — clone, install, symlink into an Obsidian vault, run the dev build.
- `manual-install.md` — build and install into an existing vault.
- `run-tests.md` — unit tests (vitest) and e2e tests (wdio-obsidian-service).

See `../DOCUMENTATION_STANDARDS.md` for the format.
